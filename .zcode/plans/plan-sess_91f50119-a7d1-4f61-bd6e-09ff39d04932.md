# Re-plan: correct placement of brand, titles, and navigation

## Principle (standard docs-platform IA)

- **Brand (logo + org name)** lives in exactly one persistent place per surface — never mixed with page titles.
- **Page titles** live in the page's own header area, once per page, not in the navbar.
- **Doc title/version** on the public viewer lives in the sidebar header + breadcrumb — not the navbar.
- **Admin panel** gets its own identity shell (branded sidebar), separate from the public docs chrome.

## Surfaces & what goes where

### 1. Global navbar (simplified, all routes)
- Left: **logo + organizationName** (links to `/docs`). When `navbarType === "admin"`, a small "Admin" chip sits beside it — **outside the link**.
- **No page titles in the navbar anymore.** Remove `headerTitle`/`headerVersion` rendering from AppLayout.
- Right side unchanged (theme toggle, admin/docs switch, avatar dropdown).
- Sidebar collapse toggle gets a fixed slot so the brand never shifts between pages.

### 2. Login page
- Render **outside AppLayout** (its own full-screen route) — no navbar, it already has its own card with logo + org name + ThemeToggle.
- Fix invisible accent bar (`loginPage.module.css` `color:` → `background:`).

### 3. Public docs list (`/docs`)
- Navbar: brand only. Hero: logo+org name, "Documentation" h1, search (unchanged).
- Remove the `headerTitle: "API Documentation"` layout call — kills the stacked duplicate titles.

### 4. Public doc viewer (`/docs/:id`)
- Navbar: brand only (doc title removed from navbar).
- **Doc identity moves to the sidebar header**: doc title (h3) + `v{version}` badge side by side, above the org brand row/tree. Remove the navbar version badge and "← All Docs" button (breadcrumb `docs / {doc.title} / {page}` already covers navigation; keep error-state back buttons).
- Content area keeps breadcrumb + page h1 + prev/next — unchanged.

### 5. Admin panel (`/admin/*`)
- **AdminSidebar gets a brand header**: logo + org name + "Admin" label at its top, then nav items — **plus a missing "Account" item** (currently unreachable except by URL).
- Page titles render **once**, via each page's existing `PageHeader`/custom header. Remove the duplicated `headerTitle` navbar calls on dashboard/docsList/users/roles/settings/account.
- Editor page: keep its rich custom header (breadcrumbs, Live/Draft, chips) — it already follows the pattern.
- Fix the broken sidebar collapse: add the missing `.collapsed` rule and wire `isSidebarCollapsed` through to `DocSidebar`/`AdminSidebar` so the toggle actually works.

### 6. Cleanup
- Register the missing `/unauthorized` route (protectedRoute redirects there but it 404s today).
- Replace the leftover 📚 emoji in `sidebarManager` empty state with the logo image.
- Remove dead double `color` in `.versionBadge`; drop unused `headerTitle`/`headerVersion`/`backButton` fields from layoutContext if no longer consumed.

## Files touched
`AppLayout.tsx` + `.module.css`, `layoutContext.tsx`, `mainRouter.tsx` (login + unauthorized routes), `AdminSidebar.tsx`, `DocSidebar.tsx`, `publicDocsPage.tsx`, `publicDocViewerPage.tsx`, all admin pages' `setLayoutData` calls, `loginPage.module.css`, `sidebarManager.tsx`.
